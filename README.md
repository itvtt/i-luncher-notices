# i-luncher-notices

i-luncher 공지입니다. 모든 i-luncher(일반 · 마스터)가 시작할 때와 새로고침할 때 이 저장소의 [`공지.txt`](공지.txt)를 GitHub 에서 바로 읽습니다.
공개 저장소라 토큰이 필요 없습니다.

## 쓰는 법

`공지.txt` 를 GitHub 에서 열어 연필(편집) → 고친 뒤 **Commit changes** 로 `main` 에 저장하면 됩니다.
i-luncher 의 관리자 메뉴 → 공지 → i-luncher → **GitHub에서 편집** 도 이 파일을 엽니다.

```
첫 공지 제목
본문 첫 줄
본문 둘째 줄
---
다음 공지 제목
본문
```

- 공지마다 **첫 줄은 제목**, 다음 줄부터 본문입니다.
- 공지 사이는 `---` 만 있는 줄입니다.
- 제목이 같으면 같은 공지입니다. 본문을 고치면 이미 읽은 사람에게도 다시 알립니다.
- 읽지 않은 공지는 런처 목록 위에 띠로 보입니다. 파일을 비우면 공지가 없습니다.

## 다른 곳에서 쓸 때

런처 빌드 설정 `NOTICES_REPOSITORY`(비우면 `i-luncher-notices`, 이름만 쓰면 런처 저장소와 같은 호스트 · 소유자)와 `NOTICES_PATH`(비우면 `공지.txt`)로 정합니다.
